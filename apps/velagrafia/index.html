A saved watermark holds the text, layout, typography, protection, rights metadata and the overlay image. Export settings (format, size, color treatment, split) and the crop of the current image are not changed when one is applied. Watermarks are kept on this device; a .velagrafia.json file moves them to another device or to someone else.

Placement

Layout
Position

While you drag text, a stamp or an overlay, it is pulled toward positions calculated from the image proportions when it comes near them: the nine margin positions and the four thirds points. Moving on past a position places the item freely, and items larger than the margin frame are never pulled. The margin is a share of the short side, so it is the same on every edge. A crop keeps the mark inside the part a platform shows in its feed. Hold Alt to place freely.

Drag on the image to move the focus point.

Text position per split strip

Frame shape

Vertical text stacks the characters top to bottom, with lines running right to left, as on a seal or a hanging sign. It suits tall frames.

Drag on the image to move the stamp. Letter spacing lives under Typography and applies to every layout.

Drag the four numbered handles on the image to match the wall or object surface. The text follows true perspective, so a receding plane keeps correct foreshortening. For buildings and walls, turn on Guides above the preview and choose Perspective: align the colored lines with edges in the photo, let the handles snap to the vanishing lines, or use Fit surface to perspective.

Typography

Blend modes composite the whole watermark layer at once, as a layer would in an image editor. Knockout punches the text out of the image; export as PNG or WebP to keep the holes transparent.

Image layers

Base image

An overlay is a logo or second image above the base. Removing it keeps the base image.

Position refers to the overlay center. Parts outside the base image are cropped on export. Text and grid always sit above both images.

Collage

Combine several images into one base image. The watermark, overlay, crop, split and export then apply to the whole collage. Dropping or choosing several images at once starts a collage too.

Drag the tiles, or use the arrows, to change the order.

Arrangement

Image in cell

Range marks

Turn this on and drag over the image to add a mark. Hold Shift while dragging for a perfect square or circle. Marks appear in single, split and batch exports.

Grid

Line weight scales with the image, so the preview and the full size export look the same.

Crop

Crop edges refer to the image as you see it, including any flip.

Protection

Applies to Tile and Rays. Each repeat gets its own small offset, rotation, scale and opacity. Removal tools work best when a watermark is identical everywhere and across many images; variation breaks that consistency. Batch export gives every image its own pattern.

Embedded rights metadata (XMP)

Written into PNG and JPG exports in the same XMP fields image editors read under file info. WebP is exported without metadata.

Hidden in the lowest bit of opaque pixels, repeated across the image. PNG exports only, and it survives only if the file is not re-encoded, resized or cropped. Use it to prove that a lossless copy came from you.
